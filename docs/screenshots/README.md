# Screenshots

Drop your demo screenshots into this folder and reference them from
the top-level `README.md`. Suggested filenames and what each should
showcase:

| File           | What it should show                                                |
| -------------- | ------------------------------------------------------------------ |
| `dashboard.png`| Dashboard page — totals, average rating, distribution, recent feedback. |
| `submit.png`   | Submit feedback form with example data and validation messages.     |
| `list.png`     | Feedback list with search bar, rating filter, program filter, cards. |
| `details.png`  | Feedback details page including edit and delete actions.            |
| `edit.png`     | Edit feedback form pre-filled with existing values.                 |
| `swagger.png`  | The auto-generated Swagger UI at `/docs`.                           |

## How to capture good screenshots

- Set the browser window to ~1280×800 for crisp screenshots.
- Use realistic sample data (a name, a program and a meaningful comment).
- Crop out browser chrome and personal identifiers.
- Save as PNG; keep individual files under ~500 KB.
